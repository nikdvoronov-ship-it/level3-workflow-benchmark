# Уровень 3: Workflow + Мини-бенчмарк

## Описание задачи
Проектирование воспроизводимого workflow для создания проверенной памятки по провозу литиевых батарей в самолёте. Цель — не лучший ответ, а измеримая процедура.

## Артефакты
- [Workflow](workflow.md) — 5 узлов, контекстная стратегия, правила неопределённости
- [Рубрика бенчмарка](benchmark/rubric.md) — 3 задачи, 5 критериев (≥3 объективных)
- [Журнал выполнения](journal.md) — точки проверки человеком
- [Итерация](iteration.md) — изменение workflow на основе данных

## Результаты бенчмарка
- 18 прогонов (3 модели × 3 задачи × 2 запуска) + переформулировка
- Слепая оценка по рубрике
- Выявлена системная слабость: отсутствие формулы конвертации мА·ч → Вт·ч

## Ретроспектива
**Слабые места:**
1. Субъективные критерии «понятность» и «тон» имеют разброс ±1 балл между оценщиками.
2. Переформулировка задачи 1 дала иной разброс, чем оригинал — метрика чувствительна к формулировке.

**Следующая итерация:**
- Калибровать субъективные критерии на 3 эталонных ответах перед оценкой.
- Добавить в workflow узел «тест на переформулировку» как обязательную проверку устойчивости.
