# Журнал выполнения workflow

## Точки проверки человеком

| Этап | Решение человека | Обоснование |
|------|------------------|-------------|
| Baseline → RCTF | Добавлена роль «эксперт IATA» и запрет на выдумывание | Модель в baseline дала vague-ответ без цифр |
| Генерация v2 → Фактчекинг | Выбраны 3 утверждения для проверки | Лимиты Wh, запрет на багаж, защита контактов — критичны для безопасности |
| Фактчекинг → Редактура | Добавлена формула mAh→Wh и дисклеймер про Китай | Модель не учла, что пользователи не знают конвертацию; правила Китая строже IATA |

## Промежуточные результаты
- Baseline: сплошной текст, нет цифр, фраза «очень большие батареи» бесполезна.
- RCTF v2: появилась структура, лимиты 100/160 Wh, правило защиты контактов.
- После проверки: добавлена формула `(mAh × V) / 1000`, уточнено «одобрение при регистрации», добавлен дисклеймер про лоукостеров.
